Autre chose : coller une image, une commande « docker run » ou un docker-compose.yml

Colle juste le nom d'une image (ex. grafana/grafana) pour que Wappos essaie de détecter automatiquement le port et le volume de données qu'elle déclare, ou colle une commande « docker run »/un docker-compose.yml complet.

Ce docker-compose.yml déclare plusieurs services — choisis celui à exposer via Wappos/SSO. Les autres démarreront à ses côtés comme dépendances internes (base de données, cache...), non accessibles publiquement.
